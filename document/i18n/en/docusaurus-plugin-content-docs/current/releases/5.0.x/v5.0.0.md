# v5.0.0 (2026-10-04)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dataway-embedded</artifactId>
    <version>5.0.0</version>
</dependency>
```

## Changes

- Added
  - A separate console resource module and Spring, Solon, and Hasor adapters using common `dataway.*` configuration keys.
  - JDBC and Nacos metadata modules with table and field mappings, version checks, and release history.
  - Application identities through `IdentityProvider`, with separate management and API execution interceptors.
  - Forms, file uploads, result handlers, and OpenAPI 3.0 and Swagger 2.0 documents.
  - Programmatic management through `AdminService`; `ApiService` invokes published, enabled APIs by path or ID.
- Improved
  - A framework-independent Dataway core, configured and created through `DatawayConfig`.
  - DataQL execution through `HostConfiguration → QueryManager → QueryBuilder`, with extension functions receiving `UdfParams`.
  - Docusaurus 3 documentation with shared version variables, Chinese and English indexes, and generated `llms.txt` files.

## Upgrade notes

- Modules, configuration keys, and extension contracts have changed. See [framework integrations](../../dataway/integration/buildtools.md) and [core configuration](../../dataway/configuration/core.md).
- Adapt authentication, interceptors, UDFs, and Java callers to the new interfaces. Preserve original scripts, API IDs, and release history when migrating metadata; follow the [migration guide](/blog/dataway-migration).
