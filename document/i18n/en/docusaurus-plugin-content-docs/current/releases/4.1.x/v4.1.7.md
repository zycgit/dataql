# v4.1.7 (2020-05-18)

## 新增
- [Issue 14](https://github.com/zycgit/hasor/issues/14) 新增 Microsoft SQL Server 的支持。
- [Issue I1GDPD](https://gitee.com/zycgit/hasor/issues/I1GDPD) 新增 PG 的支持。
- [Issue 41](https://github.com/zycgit/hasor/issues/41) 支持返回结果的完全自定义序列化，甚至可以自定义二进制专有协议。

## 修复
- [Issue 45](https://github.com/zycgit/hasor/issues/45) Oracle 下 `ReleaseDetail.ql` 脚本中的查询语句缺少一个 where。
