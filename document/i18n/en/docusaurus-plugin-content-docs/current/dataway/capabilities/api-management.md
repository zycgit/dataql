Dataway provides a console, Java API and management HTTP endpoints to create, update, publish, disable and delete APIs.

## Guide

- [Visual operations](management.md): find, edit and debug APIs in the console, inspect their states and restore historical content.
- [Programmatic management](programmatic.md): maintain definitions, versions and releases through AdminService or management HTTP endpoints.
