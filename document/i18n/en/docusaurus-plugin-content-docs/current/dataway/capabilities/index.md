Dataway supports API management, publication, result handlers, document generation and data source integration through the console, HTTP endpoints and Java API.

## Guide

- [API management](api-management.md): maintain definitions, states and release history through the console, AdminService or management HTTP endpoints.
- [API publication](development/index.md): choose script types, handle parameters, forms and files, configure responses and call APIs over HTTP.
- [Result handlers](result-handlers.md): select JSON, CSV, text or verification code image output and implement custom responses.
- [Document generation](document.md): generate OpenAPI and Swagger documents, define request/response models and call APIs through Swagger UI.
- [Data source integration](datasources.md): select databases by name and combine their results in one API.
