# v5.0.0（待发布）

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dataway-embedded</artifactId>
    <version>5.0.0</version>
</dependency>
```

## 更新内容

- 新增
  - 提供独立的 DataQL 引擎、SQL 执行器、控制台资源，以及 Spring、Solon、Hasor 整合模块。
  - `DatawayConfig` 统一装配存储、身份、引擎和 Web 入口；`AdminService` 提供 API 管理，`ApiService` 按路径或 ID 调用已发布且启用的 API。
  - JDBC、Nacos 元数据存储独立为扩展模块，支持表与字段映射、并发版本检查及发布历史，提供 MySQL、PostgreSQL、Oracle、SQL Server、H2 建表脚本。
  - `IdentityProvider` 接入应用身份；管理与 API 拦截器分别提供操作权限、目标接口、版本和调用来源等上下文。
  - 支持 JSON、表单、文件上传及 Header、Cookie 读写，上传缓存可配置内存阈值和临时目录，请求结束后清理。
  - 增加二进制数据模型和可扩展结果处理器，内置 Structure、Raw Value、CSV、Text、Verify Code；控制台支持 JSON、文本、表格、图像预览与文件下载。
  - 提供 OpenAPI 3.0、Swagger 2.0 文档入口，支持独立配置控制台、管理 API、业务 API 和文档路径。
  - SQL 执行器提供连接、执行拦截和事务扩展；普通 SQL、事务函数可接入 Spring、Solon、dbVisitor 的宿主事务。
  - 动态 SQL 增加 CASE/WHEN/ELSE、PAIRS 规则；补充 Hive 分页及数据库方言，支持列表绑定 JDBC 数组、二进制读写、JSON 和向量类型处理。
- 修复
  - 对齐 Java/JavaScript 运算符优先级和短路求值，修复负数、科学计数法、字符串转义、片段参数和嵌套函数退出行为。
  - 修复 Hint 传递、查询克隆、Lambda 作用域恢复，以及集合索引、字符串和集合函数、HMAC 算法选择问题。
  - 修复字符、枚举、数值布尔转换及缺失字段读取；修正数值宽度与 SQL Hint 默认值。
  - 修复动态 SQL 嵌套解析、XML trim 裁剪、分页信息同步及重复查询；修复参数符号转义，适配 [dbVisitor 驱动](https://www.dbvisitor.net/docs/drivers/about)的非关系型数据源命令。
  - 修复 CHAR/NCHAR 字符串截断和驱动结果类型识别，保留时间类型的时区偏移；配置在 JSON 序列化前校验显式 null。
- 优化
  - 引擎通过 `HostConfiguration → QueryManager → QueryBuilder` 创建查询，统一 Finder、宿主附件、UDF 与片段的扩展入口，保留独立使用和 JSR-223 接入。
  - 按 DataQL 数据模型精简类型处理器；`TypeHandler` 取消泛型及注解映射，保留显式注册和参数级配置。JSON 转换统一使用 Jackson，Cobble 升级至 `5.0.4`。
  - 控制台升级组件并独立打包，支持 Mock、代理调试及前后端分离部署；提供三大框架、Nacos 和数据转换的 Maven 示例。
  - 重整中英文文档、迁移指南和 SQL 使用手册，提供 `llms.txt`；补充引擎、存储、真实 HTTP 与文档示例测试。

## 升级说明

- 模块坐标、配置项和扩展接口已有调整，应用接入见[框架整合](../../dataway/integration/buildtools.md)；`DatawayConfig` 及默认入口见[框架配置](../../dataway/configuration/core.md)。
- UDF 调用参数改为 `UdfParams`；查询选项通过 `setHint(String, Object)` 设置。程序化管理使用 `AdminService`，程序调用已发布 API 使用 `ApiService`。
- 自定义 `TypeHandler` 使用 `Object` 参数和返回值，`AbstractTypeHandler<T>` 仍可保留具体类型；映射改用 `TypeHandlerRegistry.register(...)`，不再使用处理器映射注解或 `javaType` 参数选项，见 [SQL 类型处理器](../../dataway/engine/sql-types.md)。
- 元数据需保存原始脚本、接口 ID 和发布历史，可通过字段映射复用存储结构。身份、拦截器及扩展接口的调整见[迁移指南](/blog/dataway-migration)。
