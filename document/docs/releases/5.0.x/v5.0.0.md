# v5.0.0 (2026-10-04)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dataway-embedded</artifactId>
    <version>5.0.0</version>
</dependency>
```

## 更新内容

- 新增
  - 提供独立管理界面及 Spring、Solon、Hasor 适配器，统一使用 `dataway.*` 配置。
  - JDBC、Nacos 元数据存储独立为扩展模块，支持表和字段映射、版本检查及发布历史。
  - 通过 `IdentityProvider` 接入应用身份，分别提供管理与 API 执行拦截器。
  - 支持表单、文件上传、结果处理器，以及 OpenAPI 3.0 和 Swagger 2.0 文档。
  - `AdminService` 提供程序化管理，`ApiService` 支持按路径或 ID 调用已发布且启用的 API。
- 优化
  - Dataway 核心与宿主框架解耦，通过 `DatawayConfig` 统一配置并创建实例。
  - DataQL 通过 `HostConfiguration → QueryManager → QueryBuilder` 装配执行环境，扩展函数统一接收 `UdfParams`。
  - 文档工程升级为 Docusaurus 3，统一版本变量、中文及英文索引，并生成 `llms.txt`。

## 升级说明

- 模块、配置项和扩展接口已有调整，应用接入见[框架整合](../../dataway/integration/buildtools.md)和[框架配置](../../dataway/configuration/core.md)。
- 原有登录、拦截器、UDF 和程序调用需适配新接口；元数据迁移需保留原始脚本、接口 ID 和发布历史，步骤见[迁移指南](/blog/dataway-migration)。
