Dataway 提供控制台、Java 接口和管理 HTTP 接口，用于创建、修改、发布、停用和删除 API。

## 使用指引

- [可视化操作](management.md)：在控制台查找、编辑和调试接口，查看状态并恢复历史内容。
- [程序化管理](programmatic.md)：通过 AdminService 或管理 HTTP 接口维护定义、版本和发布记录。
