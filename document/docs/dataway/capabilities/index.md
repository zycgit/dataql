Dataway 提供 API 管理、发布、结果处理器、文档生成和数据源接入能力，支持通过控制台、HTTP 接口和 Java 接口操作。

## 使用指引

- [API 管理](api-management.md)：通过控制台、AdminService 或管理 HTTP 接口维护定义、状态和发布历史。
- [API 发布](development/index.md)：选择脚本类型，处理参数、表单和文件，配置响应并通过 HTTP 调用。
- [结果处理器](result-handlers.md)：选择 JSON、CSV、文本或验证码图片输出，并扩展自定义响应。
- [文档生成](document.md)：生成 OpenAPI、Swagger 文档，定义请求响应模型，并通过 Swagger UI 调用接口。
- [数据源接入](datasources.md)：按名称选择数据库，在一个 API 中组合多个数据源的结果。
